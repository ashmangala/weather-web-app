## What it does

- Gets weather for any city or your current location
- Shows 5-day forecast with vibes
- Confetti for sunny days because why not

## Live Demo

- https://ashmangala.github.io/weather-web-app/

## How to remix
1. Fork this repo
2. Get a free API key from openweathermap.org
3. Replace `PASTE_YOUR_API_KEY_HERE` in src/app.js
4. Deploy and flex, remember stay cool

## Built with
- vanilla JS - no frameworks, no build step
- OpenWeatherMap API
- Pure sprite and caffeine
